**Alt + K**  - комментарий, виден только в режиме редактирования  %% Комментарий %% 
**Alt + Y** - выделенный текст будет кодом
**Alt + O** - вставить блок кода
**Ctrl + T** - создать новую таблицу excel (см. https://github.com/ljcoder2015/obsidian-excel)

**Ctrl + <** отменить закрытие вкладки
**Ctrl + H** - найти и заменить
**Ctrl + F** - поиск в текущем файле
**Ctrl + Shift + F** - поиск во всех файлах
**Ctrl + /** - разделить область вниз
**%% Ctrl %% + >** - разделить область вправо
**Ctrl + N** - создать заметку по шаблону
**Alt + Э** - эмодзи
**Плагин Find orphaned files**
**Alt + U** - формирует заметку со всеми заметками и файлами, которые нигде не используются (не имеют ссылок)
**Alt + L** - формирует заметку со всеми неработающими ссылками (нет нужной заметки или файла на который ведет ссылка)
**Alt + P** - формирует заметку со всеми пустыми заметками
**Alt + T** - формирует заметку со всеми файлами без тегов
